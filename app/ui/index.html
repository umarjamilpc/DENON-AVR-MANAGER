Help

              
How to use DENON AVR MANAGER and what each app setting does.

            

          


          

            

              
What this app does

              

                This manager mirrors the AVR’s Setup Menu over HTTP (the same
                SETUP pages Denon’s web UI uses). It is tested on the AVR-X1200W.
                The AVR address comes only from DENON_HOST in Docker Compose — you
                cannot change it from the browser.
              

            


            

              
Main Zone power

              

                The power button at the top toggles Main Zone between On and
                Standby. Standby still keeps network control alive; a full unplug /
                power cut is different and the app will show the AVR as unreachable.
              

            


            

              
Dashboard

              

                The home screen is a customisable dashboard. Press Customize
                to add sections, add favourite controls from less or more catalogs, and
                drag sections or widgets to reorder. Layout is saved in SQLite
                (/data/app.db) and survives reboots.
              

            


            

              
Control Panel

              

                Under Settings → Control Panel layout choose:
              

              
    
                
  • less controls — full catalog, but On/Off pairs become one toggle; dropdowns stay dropdowns.
    • 
                
  • more controls — every discrete button (On and Standby separately, queries, network keys, …).
    • 
              

              

                Each section has a More + button (session only) to peek at
                the full discrete list for that section without changing Settings.
              

              

                At server start status is preloaded into a shared cache — switching
                sections uses that cache. Use Refresh for a full
                re-read. Denon allows only one telnet (TCP 23) client.
              

            


            

              
Edit modes

              
    
                
  • Realtime — most controls write to the AVR as you change them.
    • 
                
  • Save mode — edit locally, then press Save in the editor to write and refresh.
    • 
              

            


            

              
Setup Menu

              
    
                
  • Pick a section (Audio, Video, Speakers, …) then an item.
    • 
                
  • In Realtime, most pages apply when you change a control.
    • 
                
  • Some actions still need an explicit Set / Save (levels, rename, network, Manual EQ bands).
    • 
                
  • Greyed (“inactive”) items match Denon — usually the current input, amp assign, or signal does not allow that page.
    • 
                
  • In Save mode, Save writes pending edits and re-reads the open page.
    • 
              

            


            

              
Manual EQ

              

                Turn Graphic EQ On, pick speaker / channel, drag bands, then press
                Set. Channel names come from the AVR (they change with Amp Assign).
                Remote changes are only applied after the Manual EQ confirm time (see Settings).
              

              

                Export all channels saves every live curve plus Amp Assign.
                Import is blocked if Amp Assign differs; speakers in the file that are
                not on the AVR now are skipped with a warning.
              

            


            

              
Network & firmware (caution)

              

                Network Settings / Connection never auto-save. Save or Connect can
                reset the AVR network for ~60 seconds. Firmware Update / Web Update / local upload
                can reboot the receiver — confirmations are controlled in App Settings.
              

            


            

              
Info tab

              

                Read-only status pulled from the AVR (network, firmware, zones, etc.). Press
                Refresh to reload. This does not change any settings.
              

            


            

              
App Settings (persistent)

              

                Stored as app-settings.json on the host volume
                /mnt/user/appdata/UMAR-NAS-DENON-AVR-MANAGER/
                (mounted at /data in the container). Created automatically on
                first start if missing. Survives
                docker compose pull / recreate. Shared by every browser that uses this install.
              

              

                
Remote polling

                
Periodically re-check power and the open Setup page for remote changes.

                
Poll interval (seconds)

                
Seconds between AVR checks while polling is on (default 5).

                
Manual EQ confirm time (seconds)

                
How long a remote EQ curve must stay stable before the UI applies it (default 30). Use 0 to apply on the next poll.

                
Lock settings in Standby

                
Block Setup writes while Main Zone is Standby; Power On still works.

                
Show sync timestamps

                
Footer / Manual EQ clocks for last AVR check and last applied update.

                
Color theme

                
System, Light, or Dark for this manager UI (saved on the server).

                
Confirm Network Save / Connect

                
Extra browser confirmation before network actions that can drop the LAN session.

                
Confirm firmware actions

                
Extra confirmation before Update / Add Feature / Web Update / local upload.

              

              

                DENON_HOST is not an App Setting — edit it in
                docker-compose.yml and recreate the container.
