# Denon reference material

Archived prototypes, scrape captures, and protocol docs used while building **DENON-AVR-MANAGER**. Kept for lookup when adding features — not deployed or maintained as standalone apps.

| Item | What it is |
|------|------------|
| `_denon_probe/` | Early HTML/JS captures from the AVR SETUP web UI (Manual EQ, surround params, menu scrape) |
| `denon_x1200w_api/` | First FastAPI prototype for Denon SETUP HTTP forms (superseded by DENON-AVR-MANAGER) |
| `denon_x1200w_eq/` | Standalone Manual EQ client library and scrape tools |
| `DENON-X1200W-TELNET.pdf` | Telnet protocol reference for AVR-X1200W |

**Active codebase:** repository root (`app/`, `protocol/`, `tools/`).
